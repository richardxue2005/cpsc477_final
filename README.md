# cpsc477_final

The repository contains 3 Colab notebooks, corresponding to the 3 experiments we performed. The code preview doesn't work directly in Github. However, the notebooks behave normally after downloading to your local desktop. 

Once downloaded, run the first cell of each colab file to install the necessary packages and dependencies. Afterwards, you can run every subsequent cell normally, and all downloads (for models and datasets) will be handled in those cells.
